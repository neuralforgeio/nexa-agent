🧠 Features

Everything you need to build with AI — locally, offline, free.

🛠️
11 Tools
read_file, write_file, terminal_command, generate_uuid, delegate, background processes, web_search, code_execution (HITL), file_patch, revert_file. All sandboxed to workspace.
🔍
Deep Research (new v3.2)
Reformulate → search web → fetch pages → extract facts → cross-validate → synthesize answer with citations. This agent is smarter than ask-for-answer.
🧬
33 Intelligence Modules
Self-improvement loop, error healing, knowledge caching, confidence scoring, intent classification, pattern recognition, persona adaptation, reasoning chain builder...
🔐
Security Hardened
~/.openforge/ is blocked from terminal access (prevents API key exfiltration). Secrets stored with mode 700. HITL approval for code execution. Path traversal protection.
💻
Multi-Provider
OpenAI, OpenRouter, Ollama, llama.cpp, LM Studio, vLLM, TokenRouter (routing gateway), Databricks. Custom endpoint support for ANY OpenAI-compatible API.
⚙️
Auto-Failover
If the provider fails, it automatically switches to the next healthy one. Set FORGE_FAILOVER_ENABLED=1 with a chain like tokenrouter,openai,ollama.

🔧 11 Tools

All sandboxed to the workspace. Path traversal blocked. Dangerous commands rejected.

read_file — read a file inside the workspace
write_file — write a file (1MB max, atomic)
run_terminal_command — shell exec (sandboxed cwd)
generate_uuid — UUID v4
delegate — sub-agent for focused subtasks
list_background_processes — list async procs
kill_background_process — kill async proc
web_search — DuckDuckGo + extract
code_execution — Python (HITL approval)
file_patch — atomic diff patch + backup
revert_file — rollback to previous version
